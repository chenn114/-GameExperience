# 从高考后到现在，写一些对米哈游游戏的感受
从2023年高考结束的晚上，下载了米哈游的游戏，或许命运的齿轮由此开始转动，米哈游的游戏几乎陪伴了我整个大学生活。从最初只是想在暑假打发时间，到如今已经成为生活中重要的一部分，我逐渐意识到，米哈游不仅仅是在做“游戏”，而是在用一种新的方式讲故事、表达思想、构建理想世界。
对崩铁，原神，崩坏三，绝区零都有涉猎，但主玩崩铁，其他游戏迫于时间，只是过了主线剧情和部分活动。

## <<崩坏:星穹铁道>>
崩铁可以说是本人玩的第一款，也是时间最长，投入精力最多的米家游戏（宝箱任务全收集），虽然回合制听起来可能有些无聊，但不得不承认，**米哈游把回合制玩出了花**。把“回合制”做成了一个能持续带来新鲜感与思考的系统——在形式的限制中，创造了表达的无限可能。

### 思考
这几年玩下来的最大感受就是 **这是一款年轻人做出来的给年轻人的游戏** 。作为一款长线运营的游戏，无处不在的玩梗，对时事热点的紧跟（**电梯海报**，**你好会上班啊**），真理医生的名言警句（“失败的人生同样是人生...”），无不彰显着米哈游团队的年轻思考方式，对这个的世界价值观，敢于去批判，去揭露现实生活的一角，并且以一种看似“玩世不恭”，实则积极的态度去回应。至少在，思想层面上，崩铁是站在时代前沿的，向新一代年轻人诉说着自己的思想，并且能与大多数年轻人共鸣。
### 玩法
崩铁的游戏定位是一款**放松、休闲的回合制游戏**，它**轻量但不轻浮**，视觉效果与玩法依旧不落俗套，多种的流派（直伤，dot,追加，终结技，击破，忆灵真伤等）造就了多样的玩法，加上自动战斗系统，可以有效减轻玩家负担。
不过，自动战斗在“降低负担”的同时，也削弱了玩家的“参与感”。私认为可以**引入战斗QTE机制**（类似《底特律：变人》那种即时反应事件），**在主线或活动战斗中，通过QTE提升交互性与节奏感。**
例如，成功完成QTE可提升暴击率、行动条或获得特殊语音演出，这既能增加爽感，也让玩家“参与剧情战斗”的意义更强。


BTW：感觉对怪物的设计还可以再多一点花样，比如设计一个可以随机打乱我方全体角色行动轴的怪物，击杀后打乱怪物行动轴（粗糙的描述）。或者还有双生怪物（类似齿狼与灰熊那样子的，机制可以参考《彩虹六号》防守方的机器人干员机制）

## 剧情
崩铁的剧情不止伟大，而且有哲学厚度。**从雅利洛-VI的生存命题到匹诺康尼的虚幻现实，每个星球都像是在讲述“人类的另一种可能”**。
唯一的遗憾是——同行任务（紫色剧情）更新频率变低，而那部分往往是角色人格最真实的展现。希望后续能重新重视这一形式，让角色的精神世界更加丰满。


## 原神
原神的核心魅力，在我看来不仅仅是“开放世界”，而时**开放世界下的千人千面**
无论是璃月的商业伦理、须弥的知识禁锢，还是枫丹的正义与虚伪，每一国都映射着人类文明的一个侧面。
这不是简单的冒险，而是在旅行者的视角下体验**存在的多样性**。
如果说崩铁是在宇宙里讲理想主义，那么原神就是在大陆上讲“人性”。


## 绝区零
它像是米哈游**在玩法美学上的一次新实验**：动作系统与都市氛围的结合，既快又稳，既燃又冷。
剧情方面，我特别喜欢那种**都市孤独与角色间微妙羁**的表达方式。
我认为绝区零可以在“复杂立场”上更进一步，比如塑造一个类似《冰海战记》阿谢拉特那样的角色——在**善与恶**的模糊地带游走，为信念与生存不断挣扎。那种张力，或许能让故事更具文学厚度。
